## Independent portfolio edition

This repository is a separately maintained portfolio and documentation edition by **Phoebien D. Cañete**, a member of the original team. It presents the group project alongside reorganized files, expanded technical notes, reference diagrams, and an illustrated report.

The repository retains group authorship for the original prototype, recovered firmware, and photographs. Its independent repository status does not change those credits.

## Preserved materials

- Recovered Arduino source: stored unchanged in [`firmware/AquaFlush_Original_Recovered/AquaFlush_Original_Recovered.ino`](../firmware/AquaFlush_Original_Recovered/AquaFlush_Original_Recovered.ino).

The supplied archive describes the sketch as reconstructed from a presentation screenshot after the original source file was lost. The new diagrams explain the recovered logic and inferred connections; they are not verified as-built circuit drawings.
